# CreatorDock — Free Tools for VRChat Creators

CreatorDock is a free, single-file web toolkit built for VRChat creators. Everything runs locally in your browser — no accounts, no uploads to a server, no installs.

## What's inside

- **Thumbnail Maker** — Drop in an image, pick a size preset (World 1200×900, Avatar 900×1200, Square 1024×1024, Wide 1280×720), add a title and subtitle, choose from 12 fonts, drag the text anywhere on the canvas (Canva-style), and download a finished PNG.
- **Texture Optimizer** — See your texture's real dimensions and file size, shrink it to 512 / 1024 / 2048, convert between PNG / JPEG / WebP, and download the optimized version. Built for VRChat's texture memory budgets.
- **Font Generator** — Type once, preview your text in all 12 display fonts, pick colors and background, and download any style as a PNG — or send it straight into the Thumbnail Maker.
- **Creator Directory** — A showcase for VRChat creators, worlds, avatars, and group passes, run by The Deep End (VRChat group DEEP.9922).

## How to use it

**Online:** open `index.html` from any web host, or use the live site.

**Offline / from a download (Booth, Gumroad, itch.io):** unzip and open `creatordock.html` in any modern browser. The three tools work fully offline; only the directory's VRChat links need an internet connection.

## Run your own copy (GitHub Pages)

1. Fork this repo (or upload these files to a new repo).
2. Repo **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Your copy goes live at `https://<your-username>.github.io/<repo-name>/`.
